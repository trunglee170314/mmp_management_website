# Version 1.0.0

Released 28 September 2026.

## Unreleased improvements

- Relaxed internal-workspace password policy across registration, user creation/editing and password changes/resets; removed the registration strength checklist. Required fields, confirmation, current-password checks, hashing and Admin reset permissions remain unchanged.

- Continuously scrollable Timeline, shared Add/Edit Task dialogs, inline milestone flags and contextual Task/Milestone/Group/Holiday creation.
- Milestones and Holidays overviews below the calendar, independent lazy Task lists, readable zoom and less explanatory UI text.
- Boards are now called Devices throughout the application; existing IDs, barcodes, assignments, URLs and backup storage remain compatible.
- Compact System Map toolbar, on-demand Node details, consistent edit dialogs and contextual Paste without camera jumps.
- Area selection for Nodes and Groups, consistent selection highlighting, cluster movement, immediate Node deletion and Undo recovery.
- Improved keyboard connections, inline-name cancellation, failed-save handling, clipboard recovery after source deletion and legacy parallel-connection History Restore.
- Left-drag selection/object movement and right-drag camera panning in System Map; keyboard Copy/Duplicate replaces redundant context actions.
- Task transfers between Timeline Groups (including collapsed headers/Ungrouped), date-and-Group history and keyboard Undo without success toasts.
- Consistent eight-color presets for Timeline Groups and Holidays, preserving existing stored colors.
- Retained, expanding Timeline extent with virtual calendar cells; optional sticky Task tree and stable compact bundle packing, owner/date milestone clusters and clearer ownership labels.
- Fluid workspace width for large displays and a searchable Milestone Task dropdown with keyboard support.
- Persistent manual Task order, nearest-preceding-row compact packing and connected parent/subtask branches with subtree collapse. Additive migration 0029 keeps existing Tasks unranked in their original order; reordering does not modify dates, Group membership or parent links.
- Explicit tree drag-and-drop can move Tasks into/out of parents (same Group), including whole subtrees, with previews, cycle protection, Parent Task history and conflict-safe Undo. Calendar-only sibling reordering still leaves parent links unchanged.

## Initial release

- Task Management with assignees, statuses, scopes, due dates, Action Items and change history.
- Board Management with long-form descriptions, multiple named component links, Task links, optional restoreable archives, full permanent deletion for any Board and audit history.
- Meeting Minutes with creator-as-Host defaults, automatic Writer Rotation selection, a live Draft Task queue, synchronized Action Items, inline updates, review states, PDF export, finalization and historical reopen.
- Dashboard reporting by year and current assignee, including active status and completed scope views.
- System Relationship Map with multiple free-form maps, right-click creation, drag-sized Groups, direct Node/Group popups, drag-to-connect, compact line/arrow controls, direct-relative highlighting, search, zoom, minimap, automatic layouts, restore history and 30-day Trash recovery.
- A compact System Map selector aligned with the header actions, including responsive wrapping and long-name truncation.
- A per-user Appearance selector with Automatic time-based tones from 06:00–21:00, four manual color swatches and operating-system light/dark fallback outside that window.
- In-app User Guide and versioned Release Notes.
