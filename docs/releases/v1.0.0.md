# Version 1.0.0

Released 28 September 2026.

## Initial release

- Task Management with assignees, statuses, scopes, due dates, Action Items and change history.
- Board Management with long-form descriptions, multiple named component links, Task links, optional restoreable archives, full permanent deletion for any Board and audit history.
- Meeting Minutes with creator-as-Host defaults, automatic Writer Rotation selection, a live Draft Task queue, synchronized Action Items, inline updates, review states, PDF export, finalization and historical reopen.
- Dashboard reporting by year and current assignee, including active status and completed scope views.
- System Relationship Map with multiple free-form maps, right-click creation, drag-sized Groups, direct Node/Group popups, drag-to-connect, compact line/arrow controls, direct-relative highlighting, search, zoom, minimap, automatic layouts, restore history and 30-day Trash recovery.
- A compact System Map selector aligned with the header actions, including responsive wrapping and long-name truncation.
- A per-user Appearance selector with Automatic time-based tones from 06:00–21:00, four manual color swatches and operating-system light/dark fallback outside that window.
- In-app User Guide and versioned Release Notes.
